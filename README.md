# 📚 MyBook

**MyBook** היא פלטפורמה אינטראקטיבית לספרייה דיגיטלית המשלבת קריאה, מכירה, ביקורות ואלמנטים של אינטראקציה חברתית – הכל במקום אחד.

---

## ✨ תכונות עיקריות

- 📘 **רכישת ספרים** – עיון ותחזוקת ספרייה אישית.
- 🔁 **קנייה ומכירה של ספרי יד שנייה** – ממשק נוח למכירה פרטית של ספרים.
- ⭐ **ביקורות ודירוגים** – משתמשים יכולים לדרג ולהשאיר חוות דעת.
- 🧠 **ניתוח סנטימנט לביקורות** – שילוב API של Hugging Face כדי לאבחן אם הביקורת חיובית, שלילית או ניטרלית.
- ❓ **טריוויה ספרותית** – חידונים על ספרים, סופרים ותוכן כללי.
- 👨‍💼 **מידע על סופרים** – פרופילים עם ביוגרפיה ותמונות מתוך Wikipedia.
- 🧾 **מערכת הרשמה והתחברות** – כולל אחסון מאובטח של פרטי משתמש.
- 🛠️ **ממשק אדמין** – הצגת נתוני משתמשים, ניתוח שימושים ומעקב אחרי תכנים.

---

## 🛠️ טכנולוגיות בשימוש

- **Frontend**:  
  `HTML`, `CSS`, `JavaScript`  
  UI מעוצב עם ספריות כמו `jQuery`, `UIkit`.

- **Backend**:  
  `C#`, `.NET`, `ASP.NET Web API`

- **Database**:  
  `SQL Server` לאחסון מידע על ספרים, משתמשים, טרנזקציות, ביקורות ועוד.

- **AI Integration**:  
  `Hugging Face` Sentiment Analysis API לשיפור חוויית הביקורות.
